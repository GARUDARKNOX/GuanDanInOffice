# 掼蛋 Bot AI 策略文档

## 一、牌力定位（开局判断）

| 牌力 | 判断标准 | 策略 |
|------|---------|------|
| 强牌 | 炸弹≥2 + 大牌多 + 牌整 | 当仁不让，力争头游 |
| 中牌 | 炸弹1个或中等牌力 | 边打边看，把握机会 |
| 弱牌 | 无炸或炸少 + 散牌多 | 放弃头游，全力助队友 |

## 二、自由出牌策略（领出）

### 核心原则：从最小打起，不先出大牌

1. **不能压牌的牌先出手** - 最小牌型先出（单3、对3、最小顺子等）
2. **情况不明，对子先行** - 开局不确定时出对子侦察
3. **逢五出对** - 下家敌人剩5张时出对子（5张大概率是三带二或顺子，对子能卡住）
4. **不打敌人擅长的牌型** - 敌人出过的牌型不主动出

### 出牌优先级（从先到后）
1. 最小单张（3、4等，但不能是孤张大牌）
2. 最小对子
3. 三带二（消耗三张+一对）
4. 顺子/连对（清牌效率高）
5. 三条/钢板
6. 炸弹（仅必要时）

### 禁止行为
- ❌ 先出大牌再出小牌
- ❌ 开局出炸弹
- ❌ 出单张给下家敌人接牌（尤其下家剩1张时）
- ❌ 拆炸弹出散牌

## 三、跟牌策略

### 3.1 敌人出牌时

| 场景 | 策略 |
|------|------|
| 能用最小牌压过 | 压，减少手牌 |
| 需要拆规划组才能压 | 不压，保留实力 |
| 下家敌人快走牌(≤3张) | 必须压或炸 |
| 下家敌人剩4张 | 不炸（枪不打四，可能是炸弹） |
| 下家敌人剩5张 | 必须炸（可能是三带二/顺子一把走） |
| 下家敌人剩7张 | 必须炸（可能是两套牌） |
| 下家敌人剩8张 | 不炸（三套牌炸不完） |
| 自己剩≤5张 | 炸了收尾 |
| 自己剩>15张 | 不浪费炸弹 |
| 对方打大牌(A/K+)且我有≥2炸 | 可以炸一个 |

### 3.2 队友出牌时

| 场景 | 策略 |
|------|------|
| 队友出小牌(value≤11)且有更小牌可顺 | 顺牌过（帮队友抬牌，不让对手轻松接） |
| 队友快走牌(≤5张) | 用最小牌压，减少对手接牌机会 |
| 队友出大牌(value>11)且牌多 | 不压，让队友继续出 |
| 队友出最后一手走牌 | 不压 |
| 队友出牌后自己接风 | 出队友需要的牌型 |

### 3.3 接风后出牌
- 接风后应出队友擅长的牌型（观察之前出牌）
- 如果不确定，出最小单张或对子探路

## 四、炸弹使用矩阵

### 该炸的情况
- 下家敌人剩≤3张（快走了）
- 下家敌人剩5张（一把走）
- 下家敌人剩7张（两套牌）
- 自己剩≤5张（收尾）
- 对方打大牌(A/K+)且我有≥2炸
- 队友需要接风（炸了让队友走）

### 不该炸的情况
- 对家剩4张（枪不打四，可能是炸）
- 对家剩8张（三套牌炸不完）
- 自己剩>15张（浪费）
- 只剩1个炸且对方牌还多
- 队友在出牌（不需要炸）

### 炸弹对炸弹
- 自己牌多且对方牌也多 → 不对炸
- 自己牌少或对方牌少 → 对炸
- 对方出4炸且我只剩1炸 → 保留

## 五、配合原则

### 5.1 传牌必接
- 队友出的牌型，如果自己有同类型更小的，顺一道
- 接了队友的牌上手后，回传队友相同牌型

### 5.2 送牌
- 队友剩14/9/5/3/2/1张时，送5张牌型过去
- 队友剩3/2/1张时，送对应张数的牌

### 5.3 递牌必堵
- 敌人出的牌型，能堵就堵
- 敌人想走的牌型，故意改变牌型打乱

### 5.4 牌语
- 出小单张 = 探路/求对子
- 出大单张 = 有控制力
- 出对子 = 侦察/清牌
- 出三带二 = 消耗手牌
